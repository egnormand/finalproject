For our final project, we are planning to make a messaging/forum platform. The goal of this platform would be for fellow students who may be in the same major or class to be able to message or post general questions to each other in a shared web platform, so they are able to receive and give assistance to each other in an easy to use webpage. We would use the React library to design the application and allow users to post in general forums or individually message users. 

Also in the application, there would be the main forums for different classes and then also direct messages, as well as having specific class forum reminders when a due date is nearing, and also try to add a way to send notifications to the email/computer assigned to an account.

We would use Node.js for server-side programming, and store the messages, forum posts, and user-account information in MongoDB. We will use JavaScript for client-side logic and processing, and then HTML and CSS for the design of the web pages. Lastly, for sign-in authentication, we will look into trying to use some form of WPI SSO, but if that proves to be too difficult, we can use a secure 2FA sign-on system as well.
